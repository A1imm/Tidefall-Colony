# Third-Party Assets

Tidefall Colony uses selected third-party 3D assets from Polyfork.

## Polyfork

Selected environment and prop models used in the project were obtained from:

https://polyfork.dev/

These assets are used under the Polyfork license:

https://polyfork.dev/licensing

The Polyfork license allows the assets to be used and modified in personal
and commercial projects, including distribution as part of a finished game.

Polyfork assets themselves may not be redistributed as standalone asset files.

For this reason, the original Polyfork model files are not included in the
public source repository.

Playable builds of Tidefall Colony may contain these assets as part of the
finished game.
